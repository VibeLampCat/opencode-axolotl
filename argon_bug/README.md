# 🐾 ArgonBug («Аргончик») — Desktop Mascot for OpenCode

Интерактивный десктопный маскот-оверлей **Minecraft Axolotl («Аргончик»)** для среды **OpenCode v2.2.7**, визуализирующий текущее состояние работы ИИ-агентов в реальном времени.

---

## ⚡ Особенности архитектуры

* **Sidecar-процесс с нулевым оверхедом:** Телеметрия передаётся через неблокирующий локальный сокет **UDP `127.0.0.1:51515`**. Отправка занимает менее 0.1 мс и никогда не блокирует агентский цикл OpenCode.
* **Автоматический жизненный цикл:** OpenCode автоматически запускает маскота при старте CLI/TUI и штатно закрывает его сигналом `QUIT` при выходе. Сторожевой таймер отслеживает родительский PID и гарантирует закрытие виджета при аварийном завершении терминала.
* **Чистый процедурный Pixel-Art:** Графика выполнена в стиле Minecraft Axolotl на матрице 16×11 (`Antialiasing = False`, размер пикселя 7×7 px) без внешних растровых файлов.
* **5 состояний агента:**
  1. `IDLE` (Пьёт чай) — агент готов к вводу;
  2. `THINKING` (Думает Argon) — фаза размышлений (reasoning);
  3. `WORKING` (Хуячит Flash) — стриминг кода и правка файлов (`write`/`edit`/`patch`);
  4. `TESTING` (Запуск и тесты) — вызов инструментов терминала (`bash`/`shell`/`exec`);
  5. `LIMIT` (Жук лимитает) — перехват ошибок провайдера (HTTP 429, Rate Limit, Quota Exceeded).

## 📦 Установка зависимостей

Виджет требует **Python 3.10+** и библиотеку **PySide6**:

```bash
pip install -r argon_bug/requirements.txt
```

## 🚀 Запуск и управление

### 1. Автоматический режим (с OpenCode)
Просто запустите OpenCode привычным способом:
```bash
bun dev
# или после сборки:
opencode
```
OpenCode автоматически запустит маскота в фоновом режиме.

### 2. Самотестирование (3 секунды)
Для быстрой проверки графики и сокета:
```bash
python argon_bug/main.py --test-run
```
Маскот запустится, последовательно прогонит все 5 состояний и штатно закроется через 3 секунды.

### 3. Автономный запуск с ручным управлением
```bash
python argon_bug/main.py
```
Виджет можно перетаскивать мышью в любое место экрана. По правому клику или через системный трей доступно контекстное меню с ручным выбором любого из 5 состояний.

## ⚙️ Переменные окружения

| Переменная | Описание |
|---|---|
| `OPENCODE_NO_MASCOT=1` | Отключает автозапуск маскота при старте OpenCode |
| `OPENCODE_ARGON_PATH=/path/to/main.py` | Задаёт пользовательский путь к точке входа виджета |
| `OPENCODE_ARGON_EXE=/path/to/argon_bug.exe` | Задаёт путь к скомпилированному бинарнику маскота |
| `PYTHON_PATH=/path/to/python` | Указывает конкретный интерпретатор Python для запуска |

## 🏗️ Сборка единого файла `opencode.exe` (Zero-Install)

Весь проект (OpenCode v2.2.7 + виджет «Аргончик») может быть упакован в **единый файл `opencode.exe`**, работающий на чистой Windows 10/11 без Python, Node.js или Bun.

### Локальная сборка (Windows):
```cmd
build_monolith.bat
```
Скрипт автоматически:
1. Компилирует маскота через **Nuitka** в нативный `dist\argon_bug.exe` с отключённой консолью, Windows-метаданными и защитой от ложных срабатываний Defender.
2. Прогоняет смоук-тест `--test-run`.
3. Упаковывает бинарник в сжатый gzip-пейлоад через `scripts/embed_mascot.mjs`.
4. Собирает монолитный `dist\opencode.exe` через `bun build --compile`.

### Сборка в облаке через GitHub Actions:
В репозитории настроен пайплайн `.github/workflows/release.yml`:
* Сборка запускается автоматически при пуше тега релиза (например `git tag v2.2.7-argon && git push origin v2.2.7-argon`) либо вручную в интерфейсе GitHub (**Actions -> Build and Release Monolithic OpenCode EXE -> Run workflow**).
* В релиз выкладываются готовый `opencode.exe`, SHA-256 чек-сумма и криптографическое подтверждение подлинности GitHub Artifact Attestation.
